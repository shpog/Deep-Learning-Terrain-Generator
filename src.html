src.main module

src.main.main()[source]

The primary execution script for training the Conditional High-Resolution Terrain Generator.

This function acts as the main entry point for the training pipeline. It detects available hardware (applying PyTorch’s DataParallel if multiple GPUs are found), initializes the conditional TerrainGenerator and TerrainCritic networks, applies standard weight initialization, and triggers the WGAN-GP training loop. Finally, it ensures that the trained model weights are safely written to the models directory.

src.preprocessing.clean_and_normalize(array, nodata_val, fill_value=0.0)[source]

Cleans and normalizes a numerical array to a standardized range of [-1.0, 1.0].

This process identifies valid pixels by filtering out nodata and NaN values. It then shifts the data to a baseline of zero, applies a square root transformation to handle skewed distributions, and normalizes the valid data into the [-1.0, 1.0] range. Invalid pixels are replaced with the designated fill value.

Parameters:

  • array (numpy.ndarray) – The input 2D raster array to be processed.

  • nodata_val (float or int) – The specific value representing missing or nodata pixels in the input array.

  • fill_value (float, optional) – The static value assigned to invalid or nodata pixels in the final output. Defaults to 0.0.

Returns:

The processed array normalized to the [-1.0, 1.0] range.

Return type:

numpy.ndarray

src.preprocessing.create_terrain_tensor()[source]

Orchestrates the loading, aggregation, and normalization of raw terrain and climate datasets.

This pipeline utilizes paths defined in the project’s configuration to aggregate monthly precipitation (using summation) and temperature (using average) data. It then cleans, normalizes, and stacks the elevation, precipitation, and temperature arrays into a single multi-channel tensor. Intermediate memory is actively freed during execution.

Raises:

AssertionError – If the extracted rasters for precipitation, temperature, and elevation do not share the same dimensions.

Returns:

A stacked multi-channel array of shape (3, Height, Width) representing normalized elevation, precipitation, and temperature.

Return type:

numpy.ndarray

src.train_macro.compute_gradient_penalty_unconditional(critic, real_samples, fake_samples, device)[source]

Calculates the gradient penalty for the unconditional Wasserstein GAN (WGAN-GP).

This enforces the 1-Lipschitz constraint by evaluating the critic’s gradients on random interpolations between real and generated macro terrain samples, without any external conditioning.

Parameters:

  • critic (torch.nn.Module) – The unconditional macro critic (discriminator) network.

  • real_samples (torch.Tensor) – A batch of real low-resolution macro terrain tensors.

  • fake_samples (torch.Tensor) – A batch of generated low-resolution macro terrain tensors.

  • device (torch.device) – The PyTorch device used for computation.

Returns:

The calculated unconditional gradient penalty.

Return type:

torch.Tensor

src.train_macro.main()[source]

The primary execution script for training the unconditional Macro-level Terrain Generator.

Initializes the macro generator and critic networks, configures the optimizers, and runs the WGAN-GP training loop over the specified number of epochs. It supports multi-GPU training via DataParallel, generates periodic visual checkpoints, and safely saves the model weights upon completion.

src.training.compute_gradient_loss(fake, real, mask)[source]

Computes the L1 loss between the spatial gradients of the generated and real images.

This function calculates the differences between adjacent pixels along both the x (horizontal) and y (vertical) axes to evaluate texture and structural fidelity. The loss is only calculated where the provided mask is valid.

Parameters:

  • fake (torch.Tensor) – The generated high-resolution terrain tensor.

  • real (torch.Tensor) – The ground truth high-resolution terrain tensor.

  • mask (torch.Tensor) – A binary mask indicating valid regions for gradient calculation.

Returns:

The sum of the L1 losses for the x and y spatial gradients.

Return type:

torch.Tensor

src.training.compute_gradient_penalty(critic, real_samples, fake_samples, macro_guides)[source]

Calculates the gradient penalty for the conditional Wasserstein GAN (WGAN-GP).

This enforces the Lipschitz constraint by computing the norm of the critic’s gradients with respect to random interpolations between real and generated samples, conditioned on the macro guides.

Parameters:

  • critic (torch.nn.Module) – The conditional critic (discriminator) network.

  • real_samples (torch.Tensor) – A batch of real high-resolution terrain tensors.

  • fake_samples (torch.Tensor) – A batch of generated high-resolution terrain tensors.

  • macro_guides (torch.Tensor) – The low-resolution macro guides conditioning the critic.

Returns:

The computed gradient penalty to be added to the critic’s loss.

Return type:

torch.Tensor

src.training.train_wgan(generator, critic, device)[source]

Executes the WGAN-GP training loop for the conditional high-resolution terrain generator.

This function orchestrates the adversarial training process, updating the critic multiple times per generator update. It calculates critic loss (with gradient penalty) and generator loss (supplemented by an L1 penalty), while periodically saving checkpoint images of the generated elevation data.

Parameters:

  • generator (torch.nn.Module) – The conditional terrain generator network.

  • critic (torch.nn.Module) – The conditional terrain critic network.

  • device (torch.device) – The PyTorch device (CPU or CUDA) to perform training on.

Returns:

A tuple containing the fully trained generator and critic networks.

Return type:

tuple(torch.nn.Module, torch.nn.Module)
